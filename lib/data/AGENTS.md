# Data Layer - AGENTS.md

## Overview
The `data` layer implements the repository interfaces defined in the `domain` layer. It handles:
- **Remote data sources** (API calls)
- **Local data sources** (Hive caching)
- **Models** (data transfer objects with serialization)
- **Repository implementations** (orchestrates caching + API with Result pattern)

**Key Responsibility**: Bridge between domain layer (business logic) and external data sources (APIs, databases).

## Core Concepts

### 1. Data Sources
Handle raw data access (API calls, database queries). Throw `Failure` objects, don't return `Result`.

#### `datasources/quran_remote_datasource.dart`
```dart
class QuranRemoteDataSource {
  final http.Client client;
  
  const QuranRemoteDataSource({required this.client});
  
  /// Fetch all surahs metadata
  Future<List<Map<String, dynamic>>> getAllSurahs() async {
    try {
      final response = await client.get(
        Uri.parse('${AppConstants.quranApiBaseUrl}/surah'),
        headers: {'Accept': 'application/json'},
      ).timeout(const Duration(seconds: 30));
      
      if (response.statusCode == 200) {
        final data = json.decode(response.body);
        if (data['status'] == 'OK' && data['data'] != null) {
          return List<Map<String, dynamic>>.from(data['data']);
        } else {
          throw ServerFailure(message: 'Invalid API response format');
        }
      } else {
        throw ServerFailure(
          message: 'Failed to fetch surahs: ${response.reasonPhrase}',
          code: response.statusCode,
        );
      }
    } on TimeoutException {
      throw const TimeoutFailure();
    } on http.ClientException catch (e) {
      throw NetworkFailure(message: 'Network error: ${e.message}');
    } catch (e) {
      if (e is Failure) rethrow;
      throw ServerFailure(message: 'Unexpected error: $e');
    }
  }
  
  /// Fetch specific surah with verses
  Future<Map<String, dynamic>> getSurah(int surahNumber) async {
    // Similar pattern - throws Failure on error
    final response = await client.get(
      Uri.parse('${AppConstants.quranApiBaseUrl}/surah/$surahNumber'),
    ).timeout(const Duration(seconds: 30));
    
    // ... parse and validate response
    return surahData;
  }
}
```

**Data Source Characteristics**:
- Pure functions that fetch/parse data
- Throw `Failure` objects (NetworkFailure, ServerFailure, TimeoutFailure)
- No business logic - just data access
- Timeout of 30 seconds for all HTTP calls
- Validate API response structure before returning

### 2. Models (DTOs)
Data Transfer Objects with serialization logic. Separate from domain entities.

**After creating/modifying Hive models, run**:
```bash
flutter packages pub run build_runner build --delete-conflicting-outputs
```

**Hive Model Rules**:
1. Extend `HiveObject`
2. Use `@HiveType(typeId: X)` with **unique** typeId (0-255)
3. Use `@HiveField(X)` for each persisted field
4. Add `part 'filename.g.dart';` directive
5. Run build_runner to generate adapters
6. Register adapter in `main()`: `Hive.registerAdapter(CachedSurahAdapter())`

### 3. Repository Implementation
Orchestrates data sources and implements domain repository interface.

#### `repositories/quran_repository.dart`
```dart
class QuranRepository implements QuranRepositoryInterface {
  final QuranRemoteDataSource remoteDataSource;
  final Connectivity connectivity;
  
  // Hive boxes for local storage
  late Box<CachedSurah> _surahBox;
  late Box<Bookmark> _bookmarkBox;
  late Box<ReadingProgress> _progressBox;
  
  QuranRepository({
    required this.remoteDataSource,
    required this.connectivity,
  });
  
  /// Initialize Hive boxes (called in DependencyInjection.init())
  Future<void> initialize() async {
    try {
      _surahBox = await Hive.openBox<CachedSurah>('surahs');
      _bookmarkBox = await Hive.openBox<Bookmark>('bookmarks');
      _progressBox = await Hive.openBox<ReadingProgress>('reading_progress');
    } catch (e) {
      throw StorageFailure(message: 'Failed to initialize storage: $e');
    }
  }
  
  /// Check internet connection
  Future<bool> get _hasInternetConnection async {
    try {
      final result = await connectivity.checkConnectivity();
      return result != ConnectivityResult.none;
    } catch (e) {
      return false;
    }
  }
  
  @override
  Future<Result<Surah>> getSurah(int surahNumber) async {
    try {
      // 1. Check cache first
      final cached = _surahBox.get(surahNumber);
      if (cached != null && !cached.isExpired) {
        return Success(_convertCachedSurahToEntity(cached));
      }
      
      // 2. Check network connectivity
      if (!await _hasInternetConnection) {
        // Return expired cache if no internet
        if (cached != null) {
          return Success(_convertCachedSurahToEntity(cached));
        }
        return ResultError(const NetworkFailure(
          message: 'No internet connection and no cached data'
        ));
      }
      
      // 3. Fetch from API
      final surahData = await remoteDataSource.getSurah(surahNumber);
      
      // 4. Convert to entity
      final surah = _convertApiDataToSurah(surahData);
      
      // 5. Cache the result
      final cachedSurah = _convertSurahToCached(surah);
      await _surahBox.put(surahNumber, cachedSurah);
      
      return Success(surah);
    } on Failure catch (failure) {
      return ResultError(failure);
    } catch (e) {
      return ResultError(ServerFailure(message: 'Unexpected error: $e'));
    }
  }
  
  // Conversion helpers
  Surah _convertCachedSurahToEntity(CachedSurah cached) {
    return Surah(
      number: cached.number,
      name: cached.name,
      englishName: cached.englishName,
      revelationType: cached.revelationType,
      numberOfAyahs: cached.numberOfAyahs,
      verses: cached.ayahs.map(_convertCachedAyahToVerse).toList(),
    );
  }
  
  Verse _convertCachedAyahToVerse(CachedAyah cached) {
    return Verse(
      number: cached.numberInSurah,
      arabicText: cached.text,
      translation: cached.translation,
      tafsir: cached.tafsir,
    );
  }
  
  CachedSurah _convertSurahToCached(Surah surah) {
    return CachedSurah(
      number: surah.number,
      name: surah.name,
      englishName: surah.englishName,
      revelationType: surah.revelationType,
      numberOfAyahs: surah.numberOfAyahs,
      ayahs: surah.verses.map(_convertVerseToCache).toList(),
      cachedAt: DateTime.now(),
    );
  }
}
```

**Repository Three-Tier Caching Strategy**:
1. **Check local cache** (Hive) - return if fresh (not expired)
2. **Check network connectivity** - if offline, return expired cache or error
3. **Fetch from API** - on success, update cache and return

**Critical**: Always wrap data source calls in try/catch and convert exceptions to `Result<T>`.

## Caching Strategy

### Cache Expiry
- **Quran data**: 7 days (rarely changes)
- **Prayer times**: 24 hours (changes daily)
- **Audio metadata**: Not cached (URLs are CDN links)

### Cache Invalidation
```dart
// In repository
Future<void> clearCache() async {
  await _surahBox.clear();
}

Future<void> clearExpiredCache() async {
  final keys = _surahBox.keys.where((key) {
    final cached = _surahBox.get(key);
    return cached != null && cached.isExpired;
  }).toList();
  
  for (final key in keys) {
    await _surahBox.delete(key);
  }
}
```

## Error Handling in Data Layer

### Pattern: Try/Catch → Result
```dart
@override
Future<Result<T>> getData() async {
  try {
    // Data source call (can throw Failure)
    final data = await dataSource.fetchData();
    
    // Convert to entity
    final entity = _convertToEntity(data);
    
    return Success(entity);
  } on NetworkFailure catch (f) {
    return ResultError(f);
  } on ServerFailure catch (f) {
    return ResultError(f);
  } on TimeoutFailure catch (f) {
    return ResultError(f);
  } catch (e) {
    // Catch all other exceptions
    return ResultError(ServerFailure(message: 'Unexpected error: $e'));
  }
}
```

### Offline Handling
```dart
if (!await _hasInternetConnection) {
  // Try to serve from cache
  if (cachedData != null) {
    return Success(_convertToEntity(cachedData));
  }
  
  // No cache available
  return ResultError(const NetworkFailure(
    message: 'No internet connection and no cached data'
  ));
}
```

## Common Patterns

### Pattern 1: Simple Fetch with Cache
```dart
@override
Future<Result<T>> getData() async {
  try {
    // Check cache
    final cached = _box.get(key);
    if (cached != null && !cached.isExpired) {
      return Success(_convertToEntity(cached));
    }
    
    // Check network
    if (!await _hasInternetConnection) {
      return cached != null 
        ? Success(_convertToEntity(cached))
        : ResultError(NetworkFailure(message: 'No connection'));
    }
    
    // Fetch from API
    final data = await dataSource.fetch();
    
    // Cache and return
    await _box.put(key, _convertToCache(data));
    return Success(data);
  } on Failure catch (f) {
    return ResultError(f);
  } catch (e) {
    return ResultError(ServerFailure(message: '$e'));
  }
}
```

### Pattern 2: List Operations
```dart
@override
Future<Result<List<T>>> getAll() async {
  try {
    // Check cache
    final cached = _box.values.toList();
    if (cached.isNotEmpty && !cached.first.isExpired) {
      return Success(cached.map(_convertToEntity).toList());
    }
    
    // Fetch from API
    final dataList = await dataSource.fetchAll();
    
    // Clear and re-cache
    await _box.clear();
    for (final data in dataList) {
      await _box.put(data.id, _convertToCache(data));
    }
    
    return Success(dataList.map(_convertToEntity).toList());
  } on Failure catch (f) {
    return ResultError(f);
  } catch (e) {
    return ResultError(ServerFailure(message: '$e'));
  }
}
```

### Pattern 3: Write Operations (No Cache)
```dart
@override
Future<Result<void>> saveData(T entity) async {
  try {
    // Convert entity to cache model
    final cached = _convertToCache(entity);
    
    // Save to Hive
    await _box.put(entity.id, cached);
    
    return Success(null);
  } catch (e) {
    return ResultError(StorageFailure(message: 'Failed to save: $e'));
  }
}
```

### Pattern 4: Search Operations
```dart
@override
Future<Result<List<T>>> search(String query) async {
  try {
    // Search in cache first
    final cached = _box.values.where((item) {
      return item.name.toLowerCase().contains(query.toLowerCase());
    }).toList();
    
    if (cached.isNotEmpty) {
      return Success(cached.map(_convertToEntity).toList());
    }
    
    // If cache empty, fetch from API
    final results = await dataSource.search(query);
    return Success(results.map(_convertToEntity).toList());
  } on Failure catch (f) {
    return ResultError(f);
  } catch (e) {
    return ResultError(ServerFailure(message: '$e'));
  }
}
```

## Common Pitfalls

### ❌ Don't: Return Result from Data Source
```dart
// data_source.dart - WRONG
Future<Result<T>> fetch() async { ... }
```

### ✅ Do: Throw Failures from Data Source
```dart
// data_source.dart - CORRECT
Future<T> fetch() async {
  if (error) throw ServerFailure(message: '...');
  return data;
}
```

### ❌ Don't: Forget to Register Hive Adapters
```dart
// main.dart
Hive.registerAdapter(CachedSurahAdapter()); // ✅ MUST DO
await Hive.openBox<CachedSurah>('surahs');  // ❌ Will fail without adapter
```

### ❌ Don't: Use Same typeId for Multiple Models
```dart
@HiveType(typeId: 0)
class ModelA { ... }

@HiveType(typeId: 0) // ❌ WRONG - duplicate typeId
class ModelB { ... }
```

### ✅ Do: Use Unique typeIds (0-255)
```dart
@HiveType(typeId: 0)
class CachedSurah { ... }

@HiveType(typeId: 1)
class CachedAyah { ... }

@HiveType(typeId: 2)
class Bookmark { ... }
```
